玄枢录

隐私政策

适用于网页版 · Windows 桌面版 · Android 版

生效日期：2026 年 9 月 4 日 最后更新：2026 年 9 月 4 日

本政策的核心结论：你的游戏存档只存在你自己的设备上，我们不收集、也无法读取它。

游戏没有账号体系，不上传存档，不做云同步，也不接入任何第三方服务：页面不加载外部脚本、不发任何外部请求，断网与联网的表现完全一致（详见第六节）。

一、简介

《玄枢录》是一款纯单机的文字修仙放置游戏。我们尊重并保护你的隐私。

本政策说明游戏如何处理（以及为何几乎不处理）你的数据。游戏为开源项目，你可以在 GitHub 仓库 中逐行核对本政策的每一条声明。

二、我们不收集哪些信息

游戏不会收集、也不会向我们发送以下任何信息：

  • 姓名、手机号、邮箱、身份证件等身份信息
  • 设备标识符（IMEI、Android ID、广告 ID、MAC 地址等）
  • 精确位置信息
  • 通讯录、短信、通话记录
  • 相册、摄像头、麦克风
  • 应用列表、剪贴板内容
  • 你的游戏存档内容（道号、境界、装备、进度等一概不上传）

游戏不要求注册或登录，不存在账号，我们没有任何可以标识到你个人的资料。

没有例外：页面不加载任何外部脚本，也不发起任何外部请求——所以上述任何一项都不会因为"访问"而离开你的设备。详见第六节。

三、游戏在你设备上保存了什么

游戏需要记住你的存档，这些数据只写在你自己的设备上：

类别 具体内容
游戏进度 道号、境界、修为、寿元、灵根、天赋、装备、功法、洞府、灵兽、任务、成就、图鉴、转世与终局进度
游戏设置 音量、音效开关、动效强度、战报播放速度、界面偏好等

这些内容全部由你自己在游戏中产生，其中「道号」由你自行输入——请不要填写真实姓名或任何个人敏感信息，游戏不需要它们。

四、数据存储在哪里

平台 存储位置
网页版 浏览器的 localStorage（属于你访问游戏所用的那个浏览器）
Windows 版 应用自身的用户数据目录（Electron 本地存储，不出本机）
Android 版 应用私有目录内的 WebView 本地存储（其他应用无法读取）

补充说明：

  • 存档在写入前会经 AES 加密处理，避免被随意翻阅或篡改。
  • 存档不会上传到任何服务器，也不会在你的多个设备之间同步。

清除浏览器缓存 / 站点数据会删除网页版存档；卸载客户端会删除本地存档。请在游戏「设置」中定期导出备份。

五、游戏本体不与服务器通信

游戏的玩法逻辑完全在你的设备上运行，不需要联网：

  • 游戏代码不向任何服务器发送请求（无 fetch、无 XMLHttpRequest、无第三方请求库）。
  • 没有账号服务器、没有排行榜服务器、没有云存档服务器。
  • 不做在线校验，也不发任何外部请求：断网与联网的表现完全一致，全部游戏功能正常——修炼、战斗、历练、存读档都不受影响。
  • 游戏素材（图片、音频、字体）全部随包提供，不从外部 CDN 加载。

Android 版首次启动时会做一次只在设备内部进行的存档迁移（见第七节），不涉及网络。除此之外，游戏不产生任何网络通信——断网与联网的表现完全一致。

六、第三方服务：无

本站不接入任何第三方服务。没有流量统计、没有广告与推送 SDK、没有用户画像与个性化推荐——页面不加载任何外部脚本，也不发起任何外部请求。

这意味着什么

  • 打开游戏、在游戏里切换界面、断网、联网——产生的网络行为完全一致（都为零）；
  • 你的 IP、浏览器信息、访问来路不会因为"玩游戏"而被发送给任何人（承载本站的服务器按行业惯例可能留下标准访问日志，见第七节的补充说明）；
  • 若将来需要了解使用情况，只可能采用保存在你本机的计数（在存档里，不联网、不上传），并且一定会在本节与更新记录里写明。

你可以自己验证

游戏是开源项目：在 GitHub 仓库 里搜索 http 就能核对页面与代码里没有外部请求；仓库里还有一条常驻判据——每次发布前跑一遍排版、冒烟与离线三道浏览器自检，其中会把页面发出的外域请求数出来，不为零就红。

七、各平台的补充说明

Android 版关于网络权限

安装包中声明了以下两项权限：

权限 是否实际使用 说明
INTERNET 是 仅一处用途：首次启动的本地存档迁移（见下）——不涉及网络
ACCESS_NETWORK_STATE 否 打包框架（Capacitor）模板的默认声明，游戏未读取网络状态

关于首次启动的存档迁移：为了让早期版本的玩家不丢失进度，应用在首次启动时会执行一次存档迁移——在你的设备内部临时启动一个只监听本机回环地址（localhost）的服务，读取旧版本遗留的存档数据，随即关闭。

需要如实说明的几点：

  • 整个过程完全在你的设备内部完成，数据不经过任何外部网络，不发送给我们，也不发送给任何第三方。
  • Android 系统规定，即使只监听本机回环地址也必须声明 INTERNET 权限。
  • 迁移只执行一次，完成后不再启动；全新安装且无旧存档的用户会直接跳过该流程。

除上述两项外，游戏不进行任何网络通信。你可以自行验证：拔掉网线（或开飞行模式）后功能完全正常——因为它本来就不需要网络。

游戏未申请存储、位置、相机、麦克风、通讯录、电话等任何敏感权限。

Windows 桌面版

由 Electron 打包为本地应用，不含自动更新、不含崩溃上报。存档等全部游戏数据留在本机，也不加载任何外部脚本。

网页版的托管说明

网页版是纯静态站点。还需如实告知：当你用浏览器访问任何网站时，承载该网站的服务器与网络服务商可能按照行业惯例产生标准的服务器访问日志（例如 IP 地址、访问时间、浏览器 User-Agent）。这属于 Web 访问的固有技术特性，游戏代码本身不读取、不采集、不使用这类数据，我们也不会将其与你的游戏内容关联。

八、你对数据的控制权

你对自己的存档拥有完全控制权，随时可在游戏「设置」中：

  • 导出存档 —— 生成 xuanshu-<时间戳>.save 文件保存到你的设备，用于备份或迁移。
  • 导入存档 —— 从之前导出的文件恢复进度。
  • 清空数据 —— 一键删除全部游戏数据，操作立即生效且不可撤销。

此外，你也可以通过清除浏览器站点数据（网页版）或卸载应用（客户端）来彻底删除全部数据。数据删除后不可恢复，我们也没有任何副本可供找回。

九、未成年人保护

游戏不收集可识别到个人的信息，不要求注册、不索取身份资料，也不接入任何第三方统计或画像服务，因此不存在需要监护人单独同意的个人信息处理行为。

我们不针对未成年人进行任何形式的定向推送或数据采集。若监护人对本游戏的数据处理有任何疑问，欢迎通过下方渠道联系我们。

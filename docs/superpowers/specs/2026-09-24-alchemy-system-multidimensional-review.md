# 炼丹体系 · 多维度审视与分析(发散漫游,ISS-306 续)

**日期**: 2026-09-24
**状态**: 分析 + 落地(P0 全落;P1 首期「每境第二味」落,余项记档)
**前置**: 灵草五品 + 灵石购草(见 `2026-09-24-herb-grades-and-market-design.md`)

这一份不是修订方案,是**把炼丹整根链摊开,多维度挑刺、找空洞、提机会**。
凡能安全落地的当场落地,太大/太险的记档等独立的账。

## D1 · 境界密度:哪里有丹,哪里没有

逐准入境界的可炼/掉落丹数(口径:该境 `minRealm == m`):

| 段 | 境界 | 可炼 | 掉落 |
|----|------|------|------|
| 凡品 0-4 | 炼气~化神 | 6,5,5,3,2 | 1,0,0,1,2 |
| 灵品 5-7 | 炼虚~九转 | 1,1,1 | 2,2,0 |
| **8** | **渡劫** | **0** | 1 |
| **9** | **真仙** | **0** | 1 |
| 仙品 10-13 | 玄仙~大罗 | 2,1,1,1 | 1,1,1,0 |
| 神品 14-17 | 神人~神帝 | 1,1,1,1 | 0 |
| 道品 18-20 | 混沌海 | 2,1,1 | 0 |

**发现**:
- **渡劫(8)/真仙(9) 可炼断档**:人间界收官与仙界第一境都没有可炼的新丹。
  掉落线有混沌丹(8)/仙药丹(9)垫着「每境一味」,但**炉子**在这跨界前后各空一档。
- **后期每境一味偏薄**:5,6,7,13~17,19,20 都只有 1 味可炼;神界四境(14-17)共 4 味。
  仙界+的总和(11 味)不及凡品前段 0-4 境(21 味)。
- 混沌海只有修为线(道源/混元/道祖);那里才是真正的"空"。

| 族 | 可炼线 | 顶(准入) | 空洞 |
|----|--------|-----------|------|
| 修为 exp | 凡→神品 | 混元丹(19) | 完整 |
| 灵气 qi | 凡→仙品 | 仙泉玉液(11) | **神品/道品段无灵气丹** |
| 寿元 lifespan | 凡→神品 | 无垢金丹(17) | **混沌海(18-20)无寿元可炼** |
| 悟道 wudao | 凡→神品 | 神悟丹(16) | **混沌海无悟道可炼** |

**发现**:四大空白 —— 神品/道品的灵气丹、混沌海的寿元、混沌海的悟道、
以及**整个掉落线上没有任何战斗/状态丹**(掉出来的全是即时丹,战斗中增益
只靠炼、不靠捡)。

## D3 · 效果维缺位:没有哪一类丹?

- **炼丹增益**:没有任何丹提升"出丹/双成"—— 丹房提供 `alchemyYield`,但**药**补不上,
  炼丹体系自己不吃自己的药。
- **战斗内气血**:无即时回血/战时恢复(机制层也没有战时消耗品位)。
- **气运爆点/保底**:天运丹是个 buff,没有一次性"这次必成大运"的爆点。
- **突破的"坑爹兜底"**:失败损失修为(18%)有丹药能补吗?没有"回修丹"(修为受损补偿)。
- **转世/宿慧线**:无丹(那是轮回线,不该买得到)。

按体系自洽度排,最该补的:炼丹增益(它作用于炼丹本身,最贴本轮主题)、
渡劫/真仙断档(它是纯空)。

## D4 · 命名与风味:两把尺子打架

- **形态词不齐**:散 / 丹 / 膏 / 液 / 露 / 茶 / 玉液 混用,割裂感在寿元线上最明显
  (延寿丹 → 千年延寿丹 → 万寿金丹 → 永昌丹 → 无垢金丹 —— 品阶是丹/丹/金丹/丹/金丹)。
- **品质 vs 草品 两把尺**:混沌海三丹品质标"神品"、用草却是"道品"—— 草品比品质高一级。
  可自圆(混沌海没有高于神品的品质标签),但要明白这两把尺**不是同一把**,
  别让玩家拿"品质"去猜"用什么草"。
- 名字大多贴着效果(神行=历练、破境=突破),总体良好,不做大改。

## D5 · 获取渠道:丹方只从藏经阁来

`addRecipeMastery` 的全部来源 = 开局三张 + 藏经阁钻研 + 炸炉小小长一点。
**没有任何事件/奇缘/掉落/师缘授方** —— 炼丹知识是一条单一渠道。
好处:知识进度可控;代价:玩家感知不到"世界给方",方子像从书架上自己冒出来。

## D6 · 经济:分级之后的新局面

- **高界炼低界丹 = 从草坊"回国补货"**:升仙后采不到凡品草,回灵丹这类旧方只能
  靠草坊按溢价买 —— 这是草坊的现实用途,不是 bug(见前一设计文档的"纵深审视")。
- **后期灵石泻口**:草坊 ×10 阶梯,中后期闲石有去处;草作为"保值品"只进不出。
- 加新丹后 economySim 的 avgHerbCost 会动,凡影响只准落在"不破 0.5 买得起丹"之内。

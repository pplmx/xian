# 轮回经济：深修「不可替代性」奖励 —— 设计文档（ISS-302 方案）

**日期**: 2026-09-23
**状态**: 提案（需产品拍板，未落地）
**关联问题**: ISS-302 —— 轮回经济结构性失衡（浅修最优被数学锁死，深修无理由继续这一世）

## 问题定性（readings 实证）

来源：`src/core/rebirthRoi.spec.ts`、`src/core/deepCultivationRoi.spec.ts`、`src/core/daoFruitCurve.ts`。

1. **阶数不匹配是根因**：道果 = Σ(i+1)×DAO_FRUIT_PER_MAJOR，对境界**二次**增长；耗时按约 3.3 倍/境界**指数**增长。分子二次、分母指数，效率必然单调崩塌 → **金丹（门槛=MANUAL_REBIRTH_MIN_MAJOR=2）永远是最优转世点**，不是玩家习惯，是系统逼的。
2. **调曲线/调 KNEE 改不了排序**：只改高度，不改"金丹永远赢"。
3. **两条补偿思路都走不通**（deepCultivationRoi 实测）：
   - A 案（把道果阶数提到与耗时同阶）：真仙道果放大 **268 倍** —— 把道果重新做成膨胀源。
   - B 案（纯效率补偿）：真仙需 **267 倍**等效补偿，跨三境放大 25 倍，指数发散。
   - 结论：任何"可折算成量的补偿"都在同一个陷阱里 —— 试图用可折算的量去追一条指数曲线。
4. 参照基建判断：`REBIRTH_REFERENCE_MAJOR = WORLD_BREAK_MAJOR = 9`（真仙）。可停世点 = 金丹→真仙共 **8 境**（major 2..9）。界外十二境是同一世内的长线攀登，不属于轮回经济。

## 设计判据

- **允许金丹成为最快的道果农场，本身不是问题**（玩家在在线玩，风险在场；见 offline 修复同理）。问题只有一个：**除了收割道果，系统没有任何理由让玩家把这一世继续活下去。**
- 深修回报**必须是"我是谁"（legacy / 跨世遗产）维度，而不是"效率/倍率"维度** —— 一旦可折算成倍率，就塌回 267 倍补偿陷阱。
- 遵循 `samsaraAudit` 核心原则：**保留「我是谁」，重置「我现在拥有多少」。**

## 方案：「一世道统 / 境界传承」

在金丹之上 8 个可停世境界（major 2..9），各放置一个**专属「道统传承」**，满足条件：

1. **境界门槛**：本世必须**达到**对应境界才解锁该传承（深修专属，浅修永远拿不到）。
2. **每世只能择一携带**（互斥）：转世交割时只能把**一个**已解锁传承作为「我是谁」的遗产带走。
3. **不是数值倍率，而是"能力位 / 开关"**：有界、不随道果无界增长、改变玩法结构而非堆叠战力。

### 候选传承（草案，具体每项需配少量数值测试）

| 境界 | 传承 | 我这一世要的是什么 |
|------|------|------|
| 金丹 (2) | 浴火丹心 | 转世后开局可**自选**一颗所炼之丹（而非随机起始丹药） |
| 元婴 (3) | 元婴不灭 | 本世锁定 1 个替死复活位（元婴代死） |
| 化神 (4) | 化神入微 | 炼丹/炼器/参悟的失败代价在本世获得下限钳制（不炸品） |
| 炼虚 (5) | 炼虚通感 | 提前开启一个灵兽位 / 一处前期师承 |
| 合体 (6) | 合体道果 | 本世某项悟（藏经阁/炼丹研习）获得这一个子树的速率保底 |
| 大乘 (7) | 大乘金身 | 转世后起始境界保底（从筑基起步而非炼气） |
| 渡劫 (8) | 渡劫之眼 | 本世突破成功率锁定一个下限档（不连败） |
| 真仙 (9) | 真仙道痕 | 跨世携带一个**称号/道痕**（荣誉/称号位，非攻防倍率） |

> 上表的每项都刻意做成**有界的开关/能力位**，初始意图是"换一种活法"，而不是"再多 3% 攻防"。数值测试的目标是**证明其不可被金丹浅修折算替代**，而不是把它做成效率。

### 为什么这能修排序

- 道果农场仍是快而软的（^0.9 软帽、金丹最优）—— 保留自由。
- 但深修到元婴/化神/渡劫/真仙会拿到一个**本世或跨世、金丹刷一百世也得不到的**能力位 → 深修成为"另一种目标"下的最优解。这正是 deepCultivationRoi 的结论："每境有各自独一份的回报，玩家面对的就不再是『元婴只有 58% 效率』，而是『我这一世要的是什么』。"
- **不叠加膨胀**：每个传承是互斥选一的能力位，不参与 daoFruit 的指数，是平行维度。

### 一次性 vs 重复深修

传承按"保留我是谁"原则做成**一次性命中**（解锁后对后续世持续生效/或长期持有）。重复深修同一境边际递减（已拥有），不影响浅修刷道果的自由，也避免"把每一世都手压到渡劫"才能最优 —— 玩家要权衡"这一世刷道果，还是这一世拿传承"。

## 数值 / 边界待建模（产品拍板前需给出）

- 每个传承的"能力位"具体效果需落到 `samsaraAudit` 的遗产登记表（凡跨世去留必须登记，保证最小完备）。
- 需确认它们**不改变** `expIncome`/经济/秘境等其它子系统的比值不变量（新增出口要进 economySim 模型，而不是留下 note="待补"）。
- 关键测试：8 境传承互斥择一、境界门槛正确、跨世持久、且**无法通过浅修获取**。

## 风险

- 若某传承被做成"效率位"，会重新把深修拉回倍率竞赛 → 评审红线：**任何传承不得声明为纯攻防/修速倍率**。
- 一次性命中的"手感"（过早拿到全部传承后深修又失去意义）→ 可加"传承槽数"上限或跨世冷却，作为后备节制手段。

## 范围外

- 不改道果曲线 `DAO_FRUIT_SOFT_EXP` / KNEE（那是另一个"曲线高度"问题，本方案不动）。
- 不改金丹浅修的数学最优（保留自由）。
- 不涉界外十二境（那是同一世内长线，属另一套经济）。

# 可执行规格（proposal · 细化，待拍板后按此落地）

## 机制定型：宿命传承（heritage）

把上一节的「一世道统」落成**可建模、可测试、贴既有轮回框架**的机制：

- 新增持久数据 `player.reincarnation.heritage: HeritageId[]`（已锻造、永久），**随神魂不灭，跨世不清零**（归属 `HERITAGE` 清单的 kind='legacy'，类比 `daoFruit`/`talents`）。
- 每个传承 `T` 有 **`gateMajor: 2..9`**（境界门槛）。
- **锻造规则（核心防浅修）**：
  1. 到达 `T.gateMajor` 时，若 `T` 尚未锻造 → 自动锻造并永久持有。
  2. **一世至多锻造一个**：取本世到达的最高未锻造门槛。
  3. 浅修农场（永远停在金丹/元婴以下、不越界=容错开）**永远锻造不出** guardative 门槛之上的传承。
- 效果落在**信息 / 选择 / 容错**轴，**不得声明为攻防/修速倍率**（红线，见测试 §5）。

## 数据模型（示意）

```ts
// data/heritage.ts
interface HeritageDef {
  id: string
  name: string
  gateMajor: number          // 2..9
  effect: 'bounded-flat'     // 必须是有界、平直的能力位，禁止随世缩放
  desc: string               // 文案
}
```

推荐基线 8 项（均可替换，但必须符合"金丹刷不出来 + 有界平直 + 非倍率"）：

| gateMajor | id | 名 | 跨世效果（信息/选择/容错轴） |
|---|---|---|---|
| 2 | danxin | 浴火丹心 | 转世开局**自选** 1 枚已会炼之丹（choice） |
| 3 | yuanying | 元婴凝实 | 转世保底起始境界=筑基（尊重，重置从 partial 起步） |
| 4 | baihuang | 化神百炼 | 解锁 1 个额外炼器/法宝传承位（choice） |
| 5 | tonggan | 炼虚通感 | 提前解锁一处前期灵兽位/师承线（choice） |
| 6 | shouzhuo | 合体守拙 | 丹/器/参悟失败有"保底不毁"一档（容错，非倍率） |
| 7 | daotong | 大乘道统 | 命轮可选两份题并行（choice，扩命题系统） |
| 8 | dubu | 渡劫跬步 | 渡劫失败不掉阶/不散修为 1 次（容错） |
| 9 | daoben | 真仙道痕 | 跨世保留一个称号效果位 / 一道道痕（荣誉/道痕，尊重） |

> 每项效果用**平直的一次性能力**表达「换一种活法」，而不是随世累加的百分数。这是与 daoFruit（无界次线性）最关键的区别。

## 落地钩子（reincarnation.ts）

- `player.reincarnation` 增字段 `heritage: HeritageId[]`；`sanitize` 兜底老存档缺失 → `[]`。
- **本世末结算**（`prepareReincarnation` 或 `confirmReincarnation` 前段）：
  - 计算 `mostAdvancedUnforged = max{ T.gateMajor | T 未锻造 且 player.major >= T.gateMajor }`；
  - 若有 → 记为本世的「新锻造」，写进 view（供履历/提示），并在 `confirmReincarnation` 落 `player.addHeritage(id)`。
- 跨世效果在「出生」侧施加（如起始境界/起始丹/称号位），只读 `heritage` 数组判断，不进任何数值倍率。

## 测试清单（TDD）

1. **门槛**：`forgeCandidate(major)` 只返回 `gateMajor <= major` 的未锻造传承；浅修（major < 2）永不返回。
2. **一世一悟**：同世到达多个未锻造门槛只锻造**最高**那一个。
3. **浅修农场反例（防膨胀核心）**：模拟 22.7h/18 世浅修循环（每世停元婴~合体）——断言该循环永远锻造不出 `gateMajor > 循环最高境界` 的传承；纯金丹农场永不锻造金丹以外的传承。
4. **跨世持久**：锻造后 `confirmReincarnation` 不清空 `heritage`；下一世效果生效（如起始境界/起始丹）。
5. **非倍率红线**：遍历 `HERITAGE_DEFS`，断言任何传承的 effect 都不含攻防/修速/战力百分数描述（结构断言，防止把能力位做成倍率）。
6. **遗产覆盖度量**：`samsaraAudit` 的 `HERITAGE` 新增 `heritage` 一行（kind='legacy'），`samsaraAudit.spec` 的「外物全归零、只剩荣誉/道统/世界记忆」一条据此更新。
7. **经济不变量**：传承效果不产生/消耗任何经济资源流 → 除「浴火丹心」开局自选丹这类一次性出生项外，`economySim` 全时期比值不动；涉及出生的项以 note 注明，不加新产出流。

## 拍板前需确认

- 8 项具体效果是否采用（可换，但必须守住"有界平直 + 非倍率 + 金丹刷不出"三条）。
- 锻造节奏：确认「一世至多一悟」的取舍；若嫌过慢可改为「每世至多一悟，但已有传承可重复深炼给徽记」，默认取前者的保守口径。

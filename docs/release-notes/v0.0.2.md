> 手机竖屏(390×844),图由 `bun run shots` 从本版构建自动生成。

- 世界页抬头多一行概览：几段地界、层级跨度、已过几段 —— 不必先展开路线图才知道这一世的份量
- 「换一方天地」加确认框：写清花多少道果、换完剩多少、本世路线会清零。此前点了就执行
- 突破卡与开炉卡补上期望读数：「平均约 1.4 次」「平均 1.8 炉成一炉」—— 百分比不直观，次数直观
- 世界名旁那句说明改准了：它参与成形时的难度校准，但不改写历练里的战斗
- 重铸面板的词条行给出「约 N 次」—— 洗到这一条的平均重铸次数（洗不出来的词条不给数）
- 派发前的模式行给出两行读数：「预计材料 ≈ N 件」，以及「装备 约 N 趟一件 · 丹药 约 N 趟一枚」，
  并注明按普通战计。用的都是**次数/件数**，不报概率
- 镇压那一行写清钱是怎么来的：灵石与材料按区域固定产出、不随境界变；修为红利随修炼速度涨；
  转世重修后需重新镇压

## 手册

- 补「人物」「坊市」两行（此前整份手册一次都没提过这两页）
- 补「今日天道」「此世命数」的说明
- 补「世界记忆」一节：混乱 / 稳定 / 繁盛三档怎么升、怎么落、改的是哪一路收益
- 补「重铸与封存」一节（此前全文没有这两个词）：重掷哪些词条、封存怎么计价、那句「约 N 次」是什么
- 装备行补上「多余的件可分解成器灵尘」；转世那组补上「宿敌留下」

## 工程

- 新增 `bun run release:check`：打 tag 前在本地拦下「缺发版正文、工作区不干净、版本号没换、正文图链还指着旧 tag」
- 浏览器门新增判据：路由表里的每一页都必须同时进冒烟与排版两扇门，否则红
- 把一条偶发超时的用例做稳（连跑 5 次真生成改成 2 次，判据不变）
- 界面系统名词表成为判据：今日天道 / 此世命数 / 世界记忆 / 所钟 / 道果 / 重铸 / 封存 / 分解 / 宿敌
  少一个就红，免得手册悄悄漏掉某个系统

## 这一版是什么

从凡人引气入体开始,一路修到混沌道祖:**四界二十一境**(人间界 → 仙界 → 神界 → 混沌海),
每境九层至圆满,突破要渡劫 —— 5 类天劫各有克制之法。

历练是派遣式的:派出去、等一段时间、回来看遭遇与掉落;**战斗在后台一次算完再回放**。
所以它对"没时间"是友好的:关掉页面、断网、隔一晚再回来,该发生的事一件不少。

> 换入口(或换自托管)请走游戏内的「存档 → 导出 / 导入」,别指望进度跟过去。
> **iOS 上请务必「添加到主屏幕」**:Safari 会在网页七天没被打开后清掉本地数据。

## 上手

1. **建号**:定道号、测灵根(11 种:五行 + 风雷冰光暗 + 混沌)。灵根是倾向,不锁死流派;
2. **跟着首页那张「下一步」卡走**:主线进度、当前能做的事、离线收益结算都在上面;
3. **历练攒底子**:选一处去得了的地方、定下时长,回来收遭遇与掉落;
4. **攒满修为就闭关突破** —— 突破要渡劫,失败掉修为,不掉境界;
5. 寿元耗尽入轮回:**重开不是从零**,见识、道侣与部分积累跨世保留,17 种人生主题决定新一世的命题。

## 首版里有什么

- **修行**:四界二十一境 · 突破 · 渡劫 · 转世;**63 部功法 / 141 条悟道分支**(主修、辅修、秘术三类可同时装配);
- **历练**:44 个区域 · 132 种敌人 · 81 个随机事件 + 11 类机缘,首领通关解锁下一区;
- **搭配**:10 个装备槽位 · 288 种模板 · 113 条词条 · 9 级品质;同类词条递减 + 软阈值衰减 —— **堆满不如凑组合**;
- **技艺与炼制**:9 门技艺各自成长,68 种丹药、45 件法宝;**器魂** 6 类 × 6 阶,占 3 个槽位;
- **陪伴**:14 只灵兽、10 位道侣、4 位师尊 —— 不进效率链,只让这一世活出不同的样子;
- **洞府**:营造、灵脉、设施产线,离线产出回来收一次;
- **终局**:真仙之后 4 条道途、4 重天界远征、3 种试炼、6 种契约、8 类变数,组合出每个周期都不同的规则宇宙;
- **目标**:62 个成就、32 个主线任务、29 枚称号 + 每日任务 —— 打开游戏永远知道下一步做什么;
- **离线是常态**:挂机收益、自动挑战、读档补票都按"玩家可能一周没上线"设计。

系统一览、玩法与数值口径:[docs/usage.md](https://github.com/pplmx/xian/blob/v0.0.1/docs/usage.md)

## 关于 0.0.1 这个号

<details>
<summary>为什么首版是 0.0.1,以及这一版顺手修掉了什么(点开)</summary>

- **更名之前的编号随旧提交一起作废**:1.35.0 那条线的两次发版(v1.34.0 / v1.35.0)都红在同一处、
  一次 Release 都没产出来,也没有任何使用者 pin 过它 —— 首版从 0.0.1 起算,旧 tag 已清掉。
- **Android 的签名配置**:局部变量与 `signingConfigs` 的 DSL 方法同名,Groovy 把
  `storePassword storePassword` 读成"拿 String 当闭包调",配置期直接炸。它只在口令齐备时才执行 ——
  本地不设环境变量时全绿,只有 CI 注入 Secrets 才第一次跑到那一行。
- **Electron 的隐式发布**:electron-builder 在 tag 构建上**自己去发 Release**,撞上只读 token 403,
  包已经打好了却让整条流水线白跑。改成显式 `--publish never`。

</details>

## 已知边界

- **数值是 0.x 的**:平衡还在调,曲线不承诺不变(改口径会写在发版说明里);
- **存档只在你自己的设备里**:不上传任何数据,换设备走「存档 → 导出 / 导入」;
- **首屏要加载字体子集**:楷体按需分片,冷启动解码字节约 1.1MB(上限 1.5MB);

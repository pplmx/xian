# v0.0.4

这一版做的是**两件补完**：把「走到大道尽头之后」当过一个阶段来处理，以及把界面里
那些只有字、没有画的地方逐一补上。

## 终局

- **大道尽头是一个阶段，不是一堆「没有了」**。此前 `atMaxRealm` 只被几处「改口」
  引用过，没有任何内容、入口或形态是到顶才有的 —— 玩家走到混沌道祖·圆满之后，看到的
  仍是一整套为突破准备的版式。现在修行页整章换形：「下一步」换成「大道尽头」，
  报四笔（走到哪、留下什么、**还能去哪**、兵解转世），破境卡不再出现 —— 突破不可能
  发生，一张「准备破境」的表没有意义
- **首页那一格换口**：到顶时换成终局屏，替掉兜底的「静：眼下没有下一步」——
  那是把一个阶段当成了没有内容
- **满级之后主循环不许断掉**：大道熔真与满级日课。此前到顶就是「没有任何事可做」
- **此世功业**：三生录答「这一世到底修成了什么」
- **「到顶是 228 天，而玩家只看到约 13 秒」**：到顶那一刻是全程最重的动作，
  此前唯独没有一句话

## 画

四十余处此前只有字、没有画的地方逐一补上：

- **卷首那片天**：坊市（1169 行）、三生录（1549 行）、门庭、洞府、人物 / 行囊 / 天界
  三屏的主页面反而没有画
- **各按自己是什么取景**：四十四处地界此前六成六挤在三片天上（星野 / 遗迹 / 宫阙），
  现在昆仑雪岭不与青云山麓同一道山骨；器魂三席、洞府七座、九柜藏珍、天道试炼十门、
  秘境名录十五处、玄枢图五卷、一键分解九档品质、天道熔炉四味、灵草坊五行各一副长相
- **点景加中间档**：十五处有字压着的画此前退化成了一道淡墨坡
- **「每页有没有画」做成可执行的总账**：接上了不等于看得见

## 说得清

- **试炼押道源之前**：此前没有人告诉你打不打得过
- **出行窗**：此前只说了「能拿多少」，没说「拿得到吗」
- **日课**：说得出做什么，说不出「去哪儿做」
- **逆旅契改着每一场战斗**，历练页此前一个字都不说
- **破境卡的 18% 是「裸身」的数** —— 玩家身上那一份不是它
- **「今日渡劫 ×1.08」只给裸乘数** —— 读不出它乘在什么上

## 修掉的说法错误

- **满级归来账说「可尝试突破」** —— 那是句谎话
- **「走到顶的人主线永远停在 28/32」** —— 末四条赏格一分未发
- **「已满 N / 8 条」的分母是假的** —— 三条功劳永远不满足
- **轮回台账三档相加 40，而副题写「36 项」**
- **进度条 100% 了，提示语还在说「继续寻找关键装备」**
- **「已经成路了，话还在说再补最后一步」**
- **「离小成 0%」说的是已经练成了** —— 那个 0 是已走过的比例
- **建筑卡的「现 / 将」是两个「第一个」** —— 来自不同的集合
- **「去服药」点进去是装备页** —— 链接只送到书的封面
- **参悟池不分门** —— 主修签底下那个数只有全池的 39%
- **花钱没有回执** —— 三条失败都有话说，成功那条没有
- **坏档里的道号照原样印出来** —— sanitize 修了十几个字段，唯独没修 `name`

## 无障碍

- **200% 缩放下日课的去处链接只有 15px 高** —— 追上了它为什么没被拦住：被量过，然后被扔了
- **句中嵌的按钮把逗号推到下一行** —— 屏上多出一格空白

## 真实性

- **先扣悟道点、再摇卦** —— 那条 throw 一旦真的抛，钱就白扣了
- **「道果没有任何消费出口」是假的** —— 补反向对账判据
- **「不可逆的人生选择」标着尚无宿主，而逆旅契早就做了**

## 工程

- **冒烟脚本每页第 0 个按钮是「← 返回」**，点了就离页 —— 门在量一个错的元素
- **同一个形状又出现一次** —— 这次不修一处，挡形状
- 二十余条新判据：重置披露、历练预览的 caveat、胜率的方向性、提示条的去路是动作
  不是链接、减少动效一并关掉触感、重铸预算是「至多」不是「预计」、道果的两个出口

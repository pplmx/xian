# v0.0.3

这一版没有新系统，做的是**把只在发版流水线上才跑的那几条路径修稳** ——
本地门看不到它们，前三次发版都栽在这一类代码上。

## 客户端

- **关掉开发者工具**：装好的 Windows 客户端按下 `F12` 就能改存档。现在开发菜单只在未打包时出现
- **设置改成原子落盘**：此前是覆盖写，写一半崩掉会让设置悄悄复位到默认；现在先写临时文件再改名
- **启用 `asar` 打包**：产物从 166.9MB 降到 164.1MB，并带上 Electron 的完整性校验

## Android

- **迁移器的定时器**：旧版存档迁移在 Activity 销毁后仍会弹 Toast，而那时 Activity 已经没了。
  现在销毁时摘掉整个 handler 队列
- **遮挡层的渲染轮询加上限**：原先每 200ms 无限空转，等 Vue 渲染出来才停。现在最多 150 次（30 秒），
  而遮罩本来就不是死路 —— 5 秒后「进入游戏」按钮已经浮出来
- **启动底色收成一个命名资源**：`#0d1117` 此前硬编码在七个地方，改一处漏一处，启动瞬间会闪一下别的颜色

## 网页

- **Service Worker 只清自己的缓存**：`caches` 是 origin 级的，旧的清理逻辑会误删同一域下其他应用的缓存
  （本站部署在 `pplmx.github.io/xian/`，同域还有别的项目）

## 隐私

- 隐私页说「安装包声明了**三**项权限」，而表格只列了两项（`INTERNET` 与 `WRITE_EXTERNAL_STORAGE`）。
  已改正，并补了判据：文案里的数目、表格行数、`AndroidManifest.xml` 里的 `<uses-permission>` 条数三方对账

## 工程

- **`vite-plus` 声明 1.0.0 → 1.4.0**：此前引擎包声明停在 1.0.0，实际装的就是 1.0.0，
  拖出 7 条 Dependabot 告警（其中一条 `high`）。现在与宿主 `catalog` 同版
- **引擎自检补三处防空转断言**：`verify-dist.mjs` 里有三个循环遍历从文档正则捞出来的集合，
  文档写法一变集合就静默变空，而门照常打「自检通过」
- **首屏自检补上 gzip**：本地静态服务此前不压缩，「线传字节」那一栏恒等于「解码字节」，等于没量。
  补上后线传 1256KB → 505KB，FCP 从虚高的 1128ms 回到真实的 408ms
- **发版体检的 tag-only 清单补上 `package.json`**：打包配置全写在它的 `build` 字段里，
  而 v0.0.2 栽的正是那里的 `build.win.icon`
- **转世灵根删掉一处死兜底**：`view.nextLinggen ?? rollLinggen(...)` 与契约「绝不二次 roll」矛盾。
  类型上它必非空，那段是死代码；而它一旦执行，玩家会拿到一枚没在第二程预告过的灵根

## 判据

- manifest 声明的图标尺寸必须等于 PNG 实际尺寸（`192x192` 声明配 192×192 文件）
- 页面文案里的「四类行藏」「五卷」「四册」「七类」必须等于实际数据量
- `docs/development.md` 的预算表「上限」列必须等于脚本里的默认值
- 设计文档引用的常量值必须等于代码里的实际值

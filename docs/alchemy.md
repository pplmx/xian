# 炼丹体系设计备忘

这份文档记录"为什么这颗丹这么定价、为什么这张方子这么难"—— 数值口径见
[usage.md](./usage.md) 的数值小节与 `src/core/pillValue.ts`,本文件只写**设计
上的取舍与边界**。

## 审计口径(怎么比才不算错)

全部丹药放进同一张表(`core/pillValue.spec.ts` 打印,断言守着九条法则):

- **药力统一折成等效挂机秒数**,并在**各自准入境界**取值 —— 同一枚聚气丹在炼气期
  抵半层修为、在化神期连一次呼吸都不到,不统一境界比出来的是境界差不是丹药差。
- **掉落品与可炼品各算各的账**:白捡的代价是稀有度(多少场见一枚),可炼的代价才
  是灵草、灵石与炸炉赔的料。跨线只比药力绝对值。
- **跨族不可比**:寿元按绝对年数不贬值、悟道按藏经阁速率、修速按 buff 窗口折算,
  各轴随境界走势不同,只在族内横向比较。

## 九条法则(A–H + I/I2)

头八条(A 掉落不过六成 / B 品质单调 / C 增益唯一、C2 指向的增益必须存在 / D 固定点数只入门 / E、E2、E3、E4 掉落池
非空、非入门堆砌、0~2 掉得出悟道丹、每个大境界都掉得出回气丹 / F 满额回资源须可炼 /
G 修为丹按时长计价 / H 掉落不压可炼顶端)
长期守住"白捡的不比炼的强"。本轮新增两条:

- **I 可炼难度契约**:每张可炼方在其**准入境界处** overReach ≤ 1。bearableRank(境界)
  = 境界 + 1,而 minRealm 就是这方子"该出场"的境界 —— 它若在自己该出场的境界还要
  越两级强炼,等于逼玩家要么等反超、要么赌命。审计曾抓出 6 味关键丹挂 24% 成功率
  (破境/延寿/千年/万寿/悟道/太虚),回拨档位后统一到 41%。「越阶强炼」留给 over=1
  那一档:超一阶尚有一搏。
- **I2 内容厚度契约**:五条可折算时间的可炼线,每条 ≥3 味。修速族曾只有精品聚灵
  与神品本源两端、1~17 境全空 —— 玩家中期唯一的选择是白捡的造化丹。补星驰(玄 4)
  与御风(地 6)之后,修速可炼线 4 味、药力随品阶递进(15 < 18 < 22.5 < 24 分)。
  定价特别盯着**单位材料性价比**:开局聚灵 14 草换 15 分是全家族最超值的 outlier,
  若新丹走 45/85 草的"高规格高价格"路线,就是两味没人炼的填充物。星驰/御风刻意
  压草耗(24/30)、抬强度(60%/75%),使单位材料性价比(≈3.7/3.5)反超聚灵 ——
  玩家到 4/6 境有十足理由换一味更强的。
  附注:多味修速 buff 可叠加(聚灵+星驰+御风+本源 ≈ +265%),这是既存的跨 buff
  叠加设计(单 buff 只有 2 倍时长上限,见 consumableBuffCap),全靠"炼丹成本"兜底
  —— 价格若松,这一族就会变成白嫖修速;I2 的代价契约正是第一道闸。

## 法则 J:同词条不许倒挂(本轮新增)

玩家反馈「一些丹药的效果竟然完全一样,尤其用更高级灵草炼制的,竟和低阶丹药一样」。
查下来不是文案问题,是**状态族从没被比过**:

A~I 九条管的是「白捡的不比炼的强」「同线品质单调」—— 它们都只在**同族同线**里
比药力。而状态族(buff 丹)不折算成时间,`pillGainSec` 对它恒为 0,于是
A/B/H 三条对它一条都不成立:23 味状态丹的强弱此前没有任何判据。

审计抓到的真倒挂(本轮已修):

| 词条 | 原来 | 问题 | 现在 |
| --- | --- | --- | --- |
| `damageReduction` | 护心丹(境 1)15% / 神威丹(境 15)12% / 神将丹(境 15)10% | 高阶反而更弱,草耗却是 16 → 360(22 倍) | 神威 18% / 神将 16% |
| `shieldOnStart` | 罡气散(境 1)15% / 金刚液(境 2)10% | 同上 | 金刚液 18% |
| `critDamage` | 仙力丹(境 10)30% / 神将丹(境 15)30% | 两枚同规格丹在同一格给同一个数,神将还贵 33% | 神将 42% |

判据是 `pillValue.spec` 的「法则 J」两条:

1. **同词条随准入境界单调不降** —— 只要有一味更高境界的丹在同一个词条上更弱就红;
2. **同境界同词条不许撞成同一个值** —— 神威与神将都是境 15、都有 `damageReduction`,
   撞成同一个数等于其中一味在这一格上是另一味的零成本复制。

### 掉落线内部的「两味完全一样」

同一轮审计还抓到一处**不是状态族**的重复:混沌丹(境 8)与仙药丹(境 9)的
`expSecs` 都是 5400 —— 修为一栏上写得一模一样。高一境的掉落更稀有
(285 场 vs 272 场),玩家多等十几场,拿到的药力分毫不差。

这两味被卡死在 5400 是因为**法则 A**:掉落品不许越过同规格可炼对照
(渡劫丹 9000s)的六成,5400 正是那道线。故修法不是抬仙药丹(那会变成
「白捡的比炼的强」),而是把混沌丹降到 **4860**,从下面让出层次:

| | 改前 | 改后 |
| --- | --- | --- |
| 混沌丹(境 8) | 5400s | **4860s** |
| 仙药丹(境 9) | 5400s | 5400s(顶在法则 A 的线上) |

这条也进法则 J 的第二条判据:同境界同词条不许撞成同一个值 —— 它拦的是
buff 丹那一半,而「同为掉落品的两味药力完全相同」由法则 A/B 与这条
人工审计覆盖(A 顶格、B 品质单调都不报「相等」)。

### 法则 J 的三条豁免

豁免只免「比大小」,不免「同境界撞值」;每一条都必须在本文里找得到出处,
判据会拿这份名单回查本文(写不出理由的豁免点不亮绿灯)。

- **造化丹**(掉落品,境 5,修速 40% < 聚灵丹 50% < 星驰丹 60%):与奇遇系统共用
  `bless_daoyun`,改数值会波及 events 十余处,是既存账(见下「明确不动的边界」)。
- **定心丹**(境 4,破境 8% < 破境丹 15%):破境只是它众多用处里的一格,
  主线是定心护料;破境系单加最高仍是破境丹 —— 这是「通用面」设计的直接结果。
- **本源丹**(境 18,破境 10% < 破境丹 15%):它带 `breakthroughRate +10%` 这张
  战术底牌,折算口径不建模那层价值;且它已是修速可炼线顶端。

## 明确不动的边界(勿在无新理由时重开)

- **灵乳 / 仙泉玉液 / 神泉 / 道泉**:一口回满灵气是"战术最锋利的即时效果",设计上就该
  贵而稀有(灵乳单位成本 = 回灵丹的 1.97 倍,有测试钉着一到三倍)。审计折算口径天然
  低估它 —— 那不是失配。
- **本源丹**(修速可炼顶端,性价比折算 0.24 全表最低):它带着 `breakthroughRate +10%`
  这张战术底牌,折算口径不建模;且它已是可炼线顶端(品阶/药力序都正确)。
- **定心丹的破境面只有 +8%(低于破境丹的 +15%)**:这是「通用面」设计的直接结果 ——
  破境只是定心众多用处里的一格,它的主线是定心护料;破境系单加最高仍是破境丹。
  不许按「同维度强度序」把它拉平,否则三味就变回炼丹专属工具(见概念契约)。
- **造化丹**(天品掉落却弱于精品聚灵):与奇遇系统共用 `bless_daoyun`,改数值波及
  events 十余处,是既存账,见 pillValue.spec「未处置的账」。
- ~~**掉落池 0~2 境只有妖血丹**~~:已收(本轮加 **灵犀丹**,准入 0、无方、悟道 +6)。
  0~2 期再无单味:妖血(战斗续航)+ 灵犀(悟道)双常备;法则 A 把灵犀压在悟道丹的
  六成之内(6/20 = 0.3),掉落悟道线 {灵犀 spirit 6 < 仙尘散 earth 18} 品质药力同序。
  这个缺口是按备忘里写的正确路径解决的 —— **加丹**,不是改妖血丹的数值。

## 概念契约(叙事与机制同向)

**丹药是吃下去的,作用载体是服用者自身。** 所以增益的描述必须写
「服用者状态改变 → 过程向好」,不许写「丹药直接命令外物/过程」——
炼丹炉不是你的胃,一颗丹药管不了炉温。依此立一条设计纪律:

> 凡增益/丹药,参数归属服用者(心定、安神、澄澈…),由状态间接带出外部结果;
> 若有名字像「稳炉」「控火」「淬炼」,先问一句"这药吃进谁嘴里"—— 说不通,
> 就是叙事该改,不是机制该改。

这一条还带出第二层:**这族丹不该是"炼丹专属工具"**。服下的是 静心/安神/定心
一族的通用状态丹,炼丹加成只是它众多用处里的一格。故三味各配一个
**通用面**(安神→回灵、澄心→会心、定心→破境)+ **炼丹面**(双成、心得、护料),
"对炼丹有正向作用"只是其中之一面在炼丹方向的应用。

本轮据此把原 火候/淬炼/稳炉 三味**重铸**(机制不动,只动名、述、加通用面):
火候丹 → **安神丹**(神魂安泰,通用面回灵,炼丹面双成);淬炼丹 → **澄心丹**
(心念澄澈,通用面会心,炼丹面心得);稳炉丹 → **定心丹**(心定神闲,通用面破境,
炼丹面护料) —— 彻底走"静心丹"那一路。

## 炼丹的自增益(体系吃自己的药)—— 三味齐全

- **安神丹**(回灵 +25%?+ 双成概率 +20%):`alchemyYield` 词条直连
  `engineCraft.alchemyBonus`;通用面 `qiRegen`。
- **澄心丹**(会心 +8% + 炼丹心得 +30%):`craftExpGain` 词条在
  `pillService.gainCraftExp` 处把开炉技艺经验 ×(1 + craftExpGain)接线上;
  通用面 `critRate`。
- **定心丹**(破境 +8% + 定心护料 +50%):`craftSalvage` 词条在
  `engineCraft.spentOnFail` 处把失手保料 ×(1 + craftSalvage);通用面
  `breakthroughRate`。

三个新词条都走同一套接线纪律:`types` 联合 → `statNames` 显示名 →
`fruitOutlets.VIA_RESOURCE` 效率路径 → 消费点;并且「没有安全键」红线已被
**联合覆盖交叉检查**(`union ⊆ ALL_STAT_KEYS`)机械执行 —— 新词条漏登记效率路径
即刻立红,不再是文档约定。加了词条,把它的 `craftExpGain`/`craftSalvage` 写进
`data` 某处(如 buffs)、在消费点读它,dataIntegrity「每键有写」与
vocabularyCoverage「每键有读」两道门会自动守住。
